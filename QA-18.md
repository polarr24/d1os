## Adaptive training

Actual UI activates a block, routes prescriptions into the runner, completes working sets, derives direct/indirect exposure, links recovery and reviews a later phase. Phase changes expire old prescriptions instead of silently increasing loads. Five training views are checked at 320/402/1024 CSS pixels with normal/large text, labeled controls, no duplicate IDs or document overflow.

A preregistered assignment changes actual runner rest—not total volume. Observations derive from exact completed source sets; skips persist. Pure checks complete all four assignments, exclude incomparable/near-failure work, revalidate altered source sets and leave prescriptions unchanged. New follow-up pain creates a central hold, while seated analysis remains available. Replacing a block cannot create another workout after today's completed sets.

## Replay

Real generated WebM sources decode, persist in IndexedDB, pass read-back SHA verification and deduplicate. Actual RGB frame changes are sampled. Drafts preserve annotations but reset review confirmation.

Native playback reaches the cue while the visible canvas excludes the future cue frame. Premature answers are rejected; committed reads persist before key/continuation revelation. Later correct rehearsal retains the first-answer baseline. Two native sources play/pause together; ghost comparison is explicitly approximate, not calibrated biomechanics.

Cross-workspace source reads are rejected. Recoverable trash blocks practice without deleting bytes; restore recovers the source. Offline reload retains media/coaching. JSON state excludes source binaries. Same-size corrupted media fails the fingerprint check. Film practice cannot clear physical symptoms. Three populated media views are checked at the same viewport/text combinations. No uncaught page errors or unexpected external runtime requests were observed.
