# Start here · D1OS 19.0.0 APEX

1. Extract the ZIP. Serve the `d1os` folder from an HTTPS static host or run `python -m http.server 8080` in that folder for a local preview. Open `http://localhost:8080`. Mobile offline installation needs an appropriate secure host.
2. Export your existing athlete JSON before upgrading. Keep the same host, path and browser workspace to retain local data. A downloaded HTML file does not automatically update a hosted app.
3. Open **APEX** from Today or Path. In Command, enter the actual development start, junior-year goal date, semester and school-lab context. Confirm dates with your school.
4. In Academics, enter actual transcript units with NCAA school-list references. Select each unit into one allocation bucket; do not duplicate repeated material. Review the selection and prospective 10/7 snapshot with your counselor.
5. Record field/strength observations using the existing measurement pages, then link result-sheet and witness references in Targets. Estimates and hand timing cannot pass measured electronic/single-rep targets.
6. Record the real coached calendar before a Sport handoff. State what extra work is removed/replaced and review the combined football/wrestling/track week with coach and parent. It does not add sessions.
7. Use the 24-month view for priorities and Adaptive Build for an actual approved off-season block. Calendar months do not raise loads. Film evidence retains first answers; Replay checks actual source video availability.
8. Track concrete recruiting milestones. Build and inspect the private dossier preview before downloading or sharing it. No communication is sent by the app.

For persistent shin pain, stop extra painful running/jumping and involve a parent and qualified clinician. The app’s physical symptom hold remains in force until the professional follow-up workflow is completed. Academic and seated film review remain available.

When installing/updating: check that the header and offline cache status say **19.0.0**, then verify a previous record and export again. If storage reports recovery, preserve originals with Panic export; do not clear browser storage.

See `APEX-ARCHITECTURE.md` for definitions. The app cannot guarantee D1 recruitment, varsity selection or NCAA certification.
