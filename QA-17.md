## New calculation coverage

- Equal-sized, non-overlapping field windows; endpoint versus median direction; both-window omission sensitivity.
- Exact protocol grouping, units, future dates, missing bodyweight and matched transfer windows.
- Ratio arithmetic without invented speed/body-composition predictions.
- Symptom and timetable constraints before Pareto display; scenario records never count as completed physical work.
- Complete, non-overlapping prior context windows; zero variance; linear detrending and excluded dates.
- Running speed kept separate from GH cycle work and tesamorelin visceral-fat endpoints; exact DAC/no-DAC distinction.
- Frame-rate confirmation, interval bounds and reciprocal speed bounds.
- Reviewed, distinct-answer cards; first-answer calibration and deterministic ordering when timestamps tie.
- Balanced locked film assignments, sequence enforcement, changed-key/outside-study contamination, malformed imported data.
- Isolated synthetic examples and input/analysis checksums.

## Actual browser coverage

Chromium 153.0.8010.0 with touch/viewport emulation. All ten new workflows are exercised at 320, 402 and 1024 CSS pixels with normal and large type. This is not physical iPhone 17, Safari, VoiceOver or a formal accessibility audit.

Real form submissions cover hypothesis calculations, molecule/outcome tracing, local WebM decoding/playback, manual timing annotations, card creation, committed-answer revelation, balanced film-study registration and all eight assignments.

The analysis packet is downloaded and verified, then altered to confirm a mismatch. Import selection races and packet-versus-backup rejection are exercised. Offline reload retains actual observations and symptom holds, but not example records or video bytes. External runtime requests and uncaught errors are monitored.

## Remaining release limitations

- Actual iPhone/Safari installation, supported video codecs, Files downloads, background timer behavior and screen-reader use require real-device QA.
- The scientific collection remains curated with its existing visible review dates. This patch is not an exhaustive new literature search.
- Self-reported coach and clinician reviews are not authenticated.
- No cloud accounts, encrypted storage, billing or secure multi-user service is implemented.
- No frontier-model API is connected. Calculations and decision rules are deterministic and inspectable.
- No D1 probability, company valuation, guaranteed transformation or treatment effect is established by these tests.
- GitHub deployment remains blocked by repository write permission. Downloadable and hosted versions are separate.
